# virtweb

I use libvirtd on Debian Trixie for a lot of things, and I wanted a simple web
UI for my own convenient use in seeing and accessing my libvirt VMs.

I generated this with agentic tools for that use case.

There are a handful of forked, vendored JavaScript libraries (xterm.js, noVNC,
and spice-html5). Otherwise, all of the code is Go with the standard library
and vanilla JavaScript. There are no external dependencies for the base
service and everything compiles into a single Go binary.

Authentication and authorization should be handled by a reverse proxy. No
notion of users, accounts, or permissions exist.

The e2e folder contains a Node.js project for end to end testing with
Playwright, utilizing Podman and qemu for testing against the backend.
