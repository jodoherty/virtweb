# virtweb

This README is hand-maintained by the project owner. If you are an AI
coding agent or a contributor: do not edit this file.

A web-based management dashboard for remote libvirt (KVM/QEMU) hosts:
manage virtual machines — lifecycle, serial console, VNC, SPICE — from a
browser, over SSH. No WebSocket; plain-HTTP stream transport. Single
dependency-free Go binary with an embedded vanilla-JS frontend.

The documentation that used to live here has moved to `doc/`:

- `doc/USAGE.md` — what it is, building, running and configuring,
  managing VMs, the HTTP API, console/VNC/SPICE, offline demo mode
- `doc/SECURITY.md` — the security model, TLS/mTLS and the PROXY
  protocol, reverse-proxy deployment notes
- `doc/TRANSPORT.md` — the framed stream transport (wire format v1 +
  v2) and why it exists
- `doc/TESTS.md` — the test evidence and the release gate

Repository rules for contributors and agents: `AGENTS.md`.
